# Лабораторна робота №1

У цій роботі я реалізував консольне меню з такими завданнями:

1. Обчислення площі кімнати та вартості покриття підлоги.
2. Об'єднання двох рядків.
3. Порівняння рядків.
4. Додавання слів `begin` і `end` та визначення довжини рядка.
5. Виведення рядка у зворотному порядку.
6. Порівняння довжин двох рядків.

Для виходу вибираю пункт `0`.
