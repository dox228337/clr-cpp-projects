# CLR C++ Projects

У цьому репозиторії я зібрав свої лабораторні роботи №1 та №5 з C++/CLI.

## Мої роботи

- [Лабораторна робота №1](lab1/ConsoleApplication1/ConsoleApplication1.slnx) — обчислення вартості покриття підлоги та операції над рядками.
- [Лабораторна робота №5, завдання 1](lab5/ConsoleApplication2/ConsoleApplication2.slnx) — обчислення заробітної плати працівників.
- [Лабораторна робота №5, завдання 2](lab5/ConsoleApplication3/ConsoleApplication3.slnx) — упорядкування рядків матриці за спаданням сум їхніх елементів.

## Запуск

Для запуску відкриваю потрібний файл `.slnx` у Visual Studio, вибираю конфігурацію `Debug` і платформу `x64`, після чого збираю рішення.

Потрібні MSVC `v145`, підтримка C++/CLI, Windows SDK та пакет націлювання .NET Framework 4.7.2.
